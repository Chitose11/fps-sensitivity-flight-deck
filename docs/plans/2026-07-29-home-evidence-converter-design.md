# 首页证据、五档解释与跨游戏互转设计

## 目标

让推荐过程在首页、测试过程和结果页之间保持同一套信息语言。用户应能看见测试了哪些候选灵敏度、每一档当前表现如何、最终为什么选中某一档，并能在不开始测试的情况下完成四款游戏之间的灵敏度换算。

## 信息架构

首页“最近一次推荐”不再使用六个仪表盘。存在历史时，它以结果页相同的结构展示主推荐、cm/360°、eDPI、射击命中率、置信度、四游戏等效推荐、低/主/高备选及射击证据；不存在历史时显示明确空状态。首页下方新增独立“灵敏度互转台”，包含来源游戏、来源灵敏度、DPI 和四游戏输出。换算默认保持相同物理 cm/360°，并说明 DPI 只影响距离显示，在 DPI 不变时不影响各游戏灵敏度之间的比例。

## 五档候选

`65% / 82% / 100% / 122% / 150%` 是相对于用户当前灵敏度的五个实验候选，不是最终推荐区间。设置页实时显示五档的实际游戏数值；测试页显示当前正在测试的倍率及实际数值；结果页显示五档的综合得分并标记胜出档位。低/高备选仍是最终主推荐值附近的微调值，与五个实验候选分开命名。

## 数据展示

静态射击项目实时显示命中/射击、空枪、命中率、平均反应、点击误差、路径效率和过冲。追踪项目把不适用的射击指标显示为短横线，并显示进入次数、贴合率与平均角度误差。结果对象保存汇总后的射击次数、命中、空枪、命中率、平均反应、点击误差、路径效率和过冲，结果页与首页最近结果都用同一证据组件渲染。

## 验证

验证无历史与有历史首页；验证四个来源游戏的互转与范围限制；用 `1600 DPI / 无畏契约灵敏度 2` 验证设置页显示 `1.300 / 1.640 / 2.000 / 2.440 / 3.000`；验证测试实时数据随点击更新；验证结果页五档得分、证据和四游戏换算；检查桌面目标分辨率、控制台错误与输出文件同步。
