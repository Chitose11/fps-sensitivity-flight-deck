# 夜航校准台动效增强设计

## 方案选择

采用 GSAP 3.15.0 负责首页的统一时间轴编排，原生 CSS 动画与 Web Animations API 继续负责按钮、档位、读数等轻量反馈。GSAP 压缩文件固定在 `assets/vendor/`，通过普通 `<script>` 标签加载，不依赖 CDN，因此继续支持 GitHub Pages、普通静态服务器和本地 HTML。

## 动效命题

动效不是通用的淡入上移，而是一次“夜航仪表通电、自检、锁定读数”的操作反馈：

- 焦点时刻：首页首次打开时，顶部母线扫过，品牌仪表与有效状态灯完成一次短促自检；四张主卡片同步由下向上接通并展开。
- 闭合回路：四张面板各自拥有与 1px 卡片边框重合的完整 SVG 闭合电源线，卡片之间只用位于布局间隙中的短接线连接，不允许线路穿过内容。
- 同步关系：GSAP 主时间轴以 `panelsOnline` 为统一起点，四张卡片、四条顺时针闭合线和三条短接线并行通电，避免串行等待。
- 连续性：主页、设置、移动范围、测试和结果页从与布局关系一致的方向揭开，让切屏保留空间感。
- 首帧稳定：页面在样式加载前写入短暂的 `motion-prep` 预备态，GSAP 同步接管初始透明度和裁切后才释放，避免完整卡片先闪现一帧。
- 反馈：游戏切换、按钮确认、灵敏度档位切换、倒计时节拍和结果锁定都有明确的短反馈。
- 结果：主灵敏度从测试前基线收敛到最终值，其余事实读数同步锁定；五档得分与分项条从零展开。

## 性能与无障碍

- 测试采样阶段不运行环境循环、粒子、视差或持续滤镜。
- 常规效果只使用 `transform`、`opacity`、有限 `clip-path`、亮度和短时阴影；首页完整通电链约 2.3 秒，每块面板自身的出现仍控制在 480 ms 左右。
- JavaScript 动画检测 `prefers-reduced-motion: reduce`，CSS 也保留全局降级。
- 默认内容始终可见；即使 JavaScript 动画 API 不可用，页面仍可完整操作。
- 所有动效文件随项目本地部署，不依赖第三方 CDN。
- 离开首页时立即结束未完成的首页时间轴；测试页不加载任何持续动效、粒子或 GSAP 循环。

## 验证

- JavaScript 语法检查与静态资源引用检查通过。
- 使用本地 HTTP 打开首页、设置、校准、测试与结果流程。
- 在系统减少动态效果打开时，确认页面无长位移、扫描或数值滚动。
- 测试画布采样阶段没有持续装饰动画。
