# 点击确认测试与结果页重构

## 决策

采用混合测试模型：

- 大范围转向、微小目标、连续目标切换：准星到位后必须左键射击，只有命中点击才完成目标。
- 桌面微调辅助：光标到位后必须左键点击目标。
- 平滑追踪：继续按持续贴合时间与平均角度误差计分，不强制连续点击。
- 静态目标的准星接触只改变视觉状态，不再自动计为命中。

相比纯触碰方案，该模型能采集开枪时机、点击抖动、误点和点击时角度误差；相比所有项目都强制点击，它不会污染追踪测试。

## 评分

静态目标每个候选灵敏度记录：

- `shots`：总点击数；
- `hits` / `misses`：命中与未命中；
- `reactionTotal`：目标生成到命中点击的时间；
- `clickErrorTotal`：点击瞬间准星与目标中心的角度或像素误差；
- `path` / `optimal`：实际路径与最短路径；
- `overshoots`：接近后再次远离的次数。

评分以命中准确和控制为主，速度必须与命中率耦合：

`100 × (0.35×准确率 + 0.20×反应得分×准确率 + 0.20×点击误差得分 + 0.10×路径效率 + 0.10×过冲得分 + 0.05×目标覆盖率) - 25×未命中率`

追踪保持贴合率与平均误差评分。桌面辅助不参与灵敏度档位胜负，只影响控制与置信度。

## 候选范围

现有单轮三档从固定 `0.85 / 1 / 1.15` 扩展到 `0.65 / 0.82 / 1 / 1.22 / 1.5`，每项测试按平衡顺序覆盖五档。这样输入 2.0 时不再只能得到 1.7–2.3 的狭窄结果，同时仍避免一次测试给出跨度失控的极端值。

## 结果页

移除六联圆形仪表。结果页首屏改为：

1. 当前游戏主推荐值、cm/360°、置信度与准确率；
2. 四款游戏的等效灵敏度表，统一保持同一 cm/360°；
3. 当前游戏较低、主推荐、较高三个可试用值；
4. 五项分数与简短解释。

测试页左侧加入“取消测试并返回首页”按钮。退出时停止动画、退出 Pointer Lock、清除当前测试状态，不保存未完成结果。

## 验证

- 1366×768 测试页按钮可见，测试区域不产生页面滚动。
- 静态目标接触但不点击时命中数不变；目标内点击增加命中；目标外点击增加未命中。
- 追踪仍按贴合采样，不要求点击。
- 结果页无仪表盘，四游戏换算保持相同 cm/360°。
- 完整测试、重新测试、取消测试、本地保存与历史迁移均无控制台错误。
